# Steps to building turtlemarket

1. Stock Market Tracker
  - Build the DataGrid UI (MUI X)
  - Collect EOD data from stock market API (probably Tiingo)
2. Data Component
  - Total Portfolio Graph
  - Major Indices Graph
  - Individual Stock Graphs
  - Diversification and Total Holdings
3. News Component
  - News section with marketwide updates/relevant news on held stocks
  - Card UI
  - Enable daily news updates via calls to news API
4. AI Integration
  - AI analysis of current holdings and stock market trajectory
  - Disucssion on diversification and risk
  - Upcoming events and things to watch out for in current holdings
  - Suggested outside stocks to add based on current performance/trajectory
  - Buy/Sell suggestions for short, medium, and long term holding
5. Interactivity
  - Login and Authentication
  - Ability to search and select amount of stock holdings
  - Configure investor tendencies (risk tolerance, industry interest, etc)
6. Future Plans
  - Real-time data (via WebSockets)
  - Static pages (General news tab, industry news tab, single stock data)
  - Configuration of data screens to show
  - Handling for crypto, index funds, margin trading
  - Link existing stock account?
